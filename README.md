# Expense Tracker

A responsive web application for tracking and managing daily expenses.

## Features

* Add and delete expenses
* Calculate total expenses
* Track number of transactions
* Search expenses
* Filter expenses by category
* Interactive expense analysis using Chart.js
* Data persistence using LocalStorage
* Responsive design

## Technologies

* HTML
* CSS
* JavaScript
* Chart.js
* LocalStorage

## Purpose

This project demonstrates frontend development, JavaScript DOM manipulation, browser storage, data visualization, and responsive UI design.
